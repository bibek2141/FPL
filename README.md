📌 Fantasy Premier League Dashboard
📌 A full-stack web app that tracks FPL stats, filters players, and displays performance data in a responsive UI.
📌 Features:
• Pagination
• Search/Filter
• Live API integration
• Responsive UI
• Error handling
📌 Tech Stack:
Angular | Node.js | REST API | CSS | Git | (Deployed on Vercel or Heroku)
